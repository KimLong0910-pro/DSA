# Bài 25. Chứng minh tính đúng đắn của Bubble Sort (Loop Invariant)

# Thuật toán Bubble Sorts

```python
def bubble_sort(a):
    n = len(a)

    for i in range(n - 1):
        for j in range(n - 1 - i):
            if a[j] > a[j + 1]:
                a[j], a[j + 1] = a[j + 1], a[j]

    return a
```

# Bất biến vòng lặp

Sau khi hoàn thành lượt ngoài thứ `i`:

```text
i phần tử lớn nhất của mảng
đã nằm đúng vị trí ở cuối mảng.
```

Các phần tử này sẽ không bị thay đổi nữa trong những lượt tiếp theo.

# Chứng minh

## 1. Khởi tạo (Initialization)

Trước khi vòng lặp bắt đầu:

```text
i = 0
```

Chưa có phần tử nào được cố định ở cuối mảng.

Mệnh đề:

```text
0 phần tử lớn nhất đã nằm đúng vị trí
```

luôn đúng.

Do đó bất biến đúng trước khi vòng lặp bắt đầu.

## 2. Duy trì (Maintenance)

Giả sử sau lượt thứ `i`:

```text
i phần tử lớn nhất
đã nằm đúng vị trí ở cuối mảng.
```

Xét lượt tiếp theo.

Vòng lặp trong:

```python
for j in range(n - 1 - i):
```

liên tục so sánh các cặp liền kề.

Nếu:

```python
a[j] > a[j + 1]
```

thì đổi chỗ.

Nhờ đó phần tử lớn nhất trong phần chưa sắp xếp sẽ dần dịch sang phải.

Khi kết thúc lượt này:

```text
phần tử lớn nhất còn lại
được đưa tới vị trí cuối của phần chưa sắp xếp.
```

Do đó:

```text
i + 1 phần tử lớn nhất
đã nằm đúng vị trí ở cuối mảng.
```

Bất biến tiếp tục đúng.

## 3. Kết thúc (Termination)

Vòng lặp ngoài thực hiện:

```python
n - 1
```

lượt.

Khi kết thúc:

```text
n - 1 phần tử lớn nhất
đã nằm đúng vị trí.
```

Phần tử còn lại tự động đúng vị trí.

Suy ra:

```text
toàn bộ mảng đã được sắp xếp tăng dần.
```

# Ví dụ minh họa

Mảng ban đầu:

```text
[5, 1, 4, 2, 8]
```

## Sau lượt 1

```text
[1, 4, 2, 5, 8]
```

Phần tử lớn nhất:

```text
8
```

đã ở cuối.

## Sau lượt 2

```text
[1, 2, 4, 5, 8]
```

Hai phần tử lớn nhất:

```text
5, 8
```

đã đúng vị trí.

## Sau lượt 3

```text
[1, 2, 4, 5, 8]
```

Ba phần tử lớn nhất:

```text
4, 5, 8
```

đã đúng vị trí.

Bất biến luôn được duy trì.

# Chứng minh thuật toán dừng

Vòng lặp ngoài:

```python
for i in range(n - 1)
```

chạy hữu hạn:

```text
n - 1 lần
```

Vòng lặp trong:

```python
for j in range(n - 1 - i)
```

cũng hữu hạn.

Do đó thuật toán chắc chắn kết thúc.

# Kết luận

Bubble Sort đúng vì:

1. Bất biến vòng lặp đúng trước khi bắt đầu.

2. Bất biến được duy trì sau mỗi lượt.

3. Khi vòng lặp kết thúc, bất biến suy ra toàn bộ mảng đã được sắp xếp.

4. Thuật toán luôn dừng sau hữu hạn bước.

Do đó Bubble Sort là một thuật toán sắp xếp đúng đắn.
