# Bài 7. Phân tích Amortized của append trong ArrayList

## 1. Bài toán

Trong **ArrayList (mảng động)**, thao tác `append` có hai trường hợp:

- Nếu còn chỗ trống → thêm phần tử: **O(1)**
- Nếu đầy → cấp phát mảng mới gấp đôi + copy toàn bộ phần tử: **O(n)**

Vấn đề:  
Tại sao vẫn kết luận `append = O(1)` trung bình?

## 2. Cơ chế tăng dung lượng

Dung lượng mảng tăng theo cấp số nhân:

| Lần resize | Capacity |
|------------|----------|
| 1          | 1        |
| 2          | 2        |
| 3          | 4        |
| 4          | 8        |
| ...        | ...      |

Mỗi lần resize → copy toàn bộ dữ liệu cũ.

## 3. Phân tích chi phí tổng

Giả sử thực hiện `n` lần append.

Chi phí copy xảy ra tại các mức:

```text
1 + 2 + 4 + 8 + ... + n/2
Đây là cấp số nhân:
= 2n - 1
= O(n)
```

Ngoài ra:

- mỗi phần tử được thêm 1 lần → O(n)

## 4. Tổng chi phí

```text
Tổng cost = O(n) (copy) + O(n) (append) = O(n)
```

## 5. Amortized cost

```text
Amortized cost per append = O(n) / n = O(1)
```

Kết luận:

- Worst case: O(n)
- Trung bình (amortized): O(1)

## 6. Trực giác quan trọng

- Mỗi phần tử chỉ bị copy khoảng **log n lần**
- Resize xảy ra rất ít so với số lần append
- Chi phí lớn được “chia đều” cho nhiều thao tác nhỏ

## 7. Mô phỏng bằng Python

```python
class ArrayList:
    def __init__(self):
        self.data = []
        self.suc_chua = 1
        self.size = 0

    def resize(self):
        self.suc_chua *= 2
        new_data = [0] * self.suc_chua

        for i in range(self.size):
            new_data[i] = self.data[i]

        self.data = new_data

    def append(self, gia_tri):
        if self.size == self.suc_chua:
            self.resize()

        if self.size < len(self.data):
            self.data[self.size] = gia_tri
        else:
            self.data.append(gia_tri)

        self.size += 1


# test 
arr = ArrayList()

for i in range(10):
    arr.append(i)
    print(f"append {i} | size = {arr.size} | suc_chua = {arr.suc_chua}")
```
