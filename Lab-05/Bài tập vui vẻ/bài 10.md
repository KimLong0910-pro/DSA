# Bài 10. Chọn cài đặt theo mật độ đồ thị (Dijkstra)

## 1. Bài toán

Ta xét bài toán tìm đường đi ngắn nhất từ một đỉnh nguồn trong đồ thị có trọng số không âm bằng thuật toán **Dijkstra**.
Có 2 cách cài đặt phổ biến:

- **Cài đặt 1: O(V²)**  
  - Dùng mảng khoảng cách `dist[]`
  - Mỗi bước tìm đỉnh có khoảng cách nhỏ nhất bằng duyệt tuyến tính
- **Cài đặt 2: O((V + E) log V)**  
  - Dùng **heap (priority queue)**
  - Lấy đỉnh nhỏ nhất nhanh hơn

## 2. Phân tích độ phức tạp

### 2.1. Cài đặt O(V²)

- Mỗi lần chọn đỉnh nhỏ nhất: O(V)
- Thực hiện V lần:

\[
O(V \cdot V) = O(V^2)
\]

### 2.2. Cài đặt dùng heap

- Mỗi thao tác push/pop heap: O(log V)
- Mỗi đỉnh xử lý: V
- Mỗi cạnh relax: E

\[
O((V + E)\log V)
\]

## 3. Khi nào dùng thuật toán nào?

### 3.1. Đồ thị thưa (Sparse graph)

\[
E \approx V
\]

Heap:

\[
O((V + V)\log V) = O(V \log V)
\]

So với O(V²) ⇒ heap tốt hơn

✔ **Nên dùng heap**

### 3.2. Đồ thị dày (Dense graph)

\[
E \approx V^2
\]

Heap:

\[
O((V + V^2)\log V) = O(V^2 \log V)
\]

So với O(V²) ⇒ O(V²) tốt hơn -> **Nên dùng O(V²)**

## 4. Code Python

## 4.1 Dijkstra O(V²)

```python
import math

def dijkstra_v2(n, adj, start):
    INF = math.inf
    dist = [INF] * n
    visited = [False] * n

    dist[start] = 0

    for _ in range(n):
        u = -1

        # tìm đỉnh chưa thăm có dist nhỏ nhất
        for i in range(n):
            if not visited[i] and (u == -1 or dist[i] < dist[u]):
                u = i

        if dist[u] == INF:
            break

        visited[u] = True

        for v, w in adj[u]:
            if dist[v] > dist[u] + w:
                dist[v] = dist[u] + w

    return dist
```

## 4.2 Dijkstra dùng heap (priority queue)

```python
import heapq
import math

def dijkstra_heap(n, adj, start):
    INF = math.inf
    dist = [INF] * n

    dist[start] = 0
    pq = [(0, start)]  # (distance, node)

    while pq:
        d, u = heapq.heappop(pq)

        if d != dist[u]:
            continue

        for v, w in adj[u]:
            if dist[v] > dist[u] + w:
                dist[v] = dist[u] + w
                heapq.heappush(pq, (dist[v], v))

    return dist
```
