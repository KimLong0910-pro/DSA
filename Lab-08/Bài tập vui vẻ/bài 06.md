# Bài 6. So sánh Chaining vs Open Addressing

# 1. Separate Chaining

## Ý tưởng

Mỗi bucket chứa một danh sách các phần tử bị va chạm.

Ví dụ:

```text
Bucket 0: []
Bucket 1: [('a',1), ('b',2), ('c',3)]
Bucket 2: []
```

Các key hash vào cùng bucket sẽ được lưu chung trong bucket đó.

## Ví dụ

```python
buckets = [
    [],
    [('a', 1), ('b', 2)],
    []
]

print(buckets)
```

### Output

```python
[[], [('a', 1), ('b', 2)], []]
```

## Ưu điểm

* Dễ cài đặt
* Xử lý collision đơn giản
* Xóa phần tử dễ
* Vẫn hoạt động tốt khi load factor cao

## Nhược điểm

* Tốn bộ nhớ hơn
* Cache locality kém
* Bucket dài làm tìm kiếm chậm

# 2. Open Addressing

## Ý tưởng

Toàn bộ phần tử được lưu trực tiếp trong bảng băm.

Khi collision:

* dò sang ô khác

Ví dụ với Linear Probing:

```text
i → i+1 → i+2 → ...
```

## Ví dụ

```python
bang = [
    None,
    ('a', 1),
    ('b', 2),
    None
]

print(bang)
```

### Output

```python
[None, ('a', 1), ('b', 2), None]
```

## Ưu điểm

* Tiết kiệm bộ nhớ
* Cache locality tốt
* Truy cập nhanh khi load factor thấp

## Nhược điểm

* Dễ xảy ra clustering
* Xóa phần tử khó
* Hiệu năng giảm khi bảng gần đầy

# 3. So sánh bộ nhớ

### Chaining

Ngoài bảng băm còn cần:

* linked list
* node
* pointer

→ Tốn bộ nhớ hơn

### Open Addressing

Chỉ dùng mảng chính.

→ Tiết kiệm bộ nhớ hơn

# 4. So sánh khi load factor cao

Công thức:

```text
Load Factor = n / m
```

Trong đó:

* n = số phần tử
* m = số bucket

## Chaining

Khi load factor tăng:

* bucket dài hơn
* tốc độ giảm dần

Nhưng vẫn hoạt động ổn định.

## Open Addressing

Khi load factor tăng:

* collision tăng mạnh
* probing lâu hơn

Hiệu năng giảm rõ rệt, đặc biệt khi:

```text
load factor > 0.7
```

# 5. So sánh thao tác xóa

## Chaining

Xóa đơn giản:

```python
bucket = [('a',1), ('b',2)]
bucket.remove(('a',1))

print(bucket)
```

### Output

```python
[('b', 2)]
```

## Open Addressing

Không thể xóa trực tiếp bằng `None`.

Vì sẽ làm hỏng chuỗi probing.

Cần dùng:

* tombstone
  hoặc
* rehash

Ví dụ:

```python
DELETED = object()
```

# 6. Bảng so sánh tổng hợp

| Tiêu chí           | Chaining    | Open Addressing |
| ------------------ | ----------- | --------------- |
| Bộ nhớ             | Cao hơn     | Thấp hơn        |
| Cache locality     | Kém         | Tốt             |
| Xóa phần tử        | Dễ          | Khó             |
| Collision handling | Linked list | Probing         |
| Load factor cao    | Ổn          | Giảm mạnh       |
| Cài đặt            | Dễ          | Khó hơn         |

# 7. Kết luận

### Nên dùng Chaining khi:

* Cần xóa nhiều
* Load factor cao
* Muốn code đơn giản

### Nên dùng Open Addressing khi:

* Muốn tiết kiệm bộ nhớ
* Load factor thấp
* Cần tối ưu cache

## Kết luận cuối

```text
Chaining: đơn giản, ổn định, dễ xóa
Open Addressing: tiết kiệm bộ nhớ, nhanh khi bảng còn thưa
```
