# Bài 12. Tấn công Hash Flooding

## 1. Bài toán

Hash Flooding là kỹ thuật tạo ra nhiều khóa có cùng giá trị băm, khiến tất cả rơi vào một bucket.

Khi đó, các thao tác:

- put()
- get()
- remove()

không còn trung bình **O(1)** mà suy biến thành **O(n)**.

## 2. Minh họa

Giả sử dùng hàm băm:

```text
h(k) = k mod 5
```

Các khóa:

```text
5, 10, 15, 20, 25
```

đều có:

```text
5 mod 5 = 0
10 mod 5 = 0
15 mod 5 = 0
20 mod 5 = 0
25 mod 5 = 0
```

Tất cả rơi vào cùng bucket.

## 3. Code minh họa

```python
def hash_function(k):
    return k % 5


keys = [5, 10, 15, 20, 25]

for key in keys:
    print(f"{key} -> Bucket {hash_function(key)}")
```

## Output

```text
5 -> Bucket 0
10 -> Bucket 0
15 -> Bucket 0
20 -> Bucket 0
25 -> Bucket 0
```

## 4. Hậu quả

Nếu bucket được cài bằng danh sách liên kết:

```text
Bucket 0

5 → 10 → 15 → 20 → 25
```

Khi tìm khóa 25 phải duyệt qua nhiều phần tử.

Độ phức tạp:

- Trung bình: **O(1)**
- Khi bị Hash Flooding: **O(n)**

## 5. Cách phòng chống

Một số cách phổ biến:

- Sử dụng **Universal Hashing**.
- Dùng **Secret Random Seed (Randomized Hashing)** để mỗi lần chạy chương trình sẽ có hàm băm khác nhau.
- Khi một bucket quá dài, chuyển sang cấu trúc dữ liệu khác (ví dụ cây cân bằng như trong Java HashMap).

Nhờ đó, kẻ tấn công rất khó tạo ra nhiều khóa cùng bucket.

## 6. Kết luận

Hash Flooding là tấn công tạo nhiều va chạm có chủ đích, làm bảng băm suy giảm từ **O(1)** xuống **O(n)** mỗi thao tác.

Việc sử dụng hàm băm ngẫu nhiên hóa hoặc Universal Hashing giúp giảm đáng kể nguy cơ này.

## Complexity

| Trường hợp    | Độ phức tạp |
|-------------- |------------:|
| Trung bình    | O(1)        |
| Hash Flooding | O(n)        |
